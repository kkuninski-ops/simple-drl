# Circuit 4 — S32 Dimmer Knob → Radio Volume Control
## Заводската врътка за осветление управлява силата на звука на радиото

Заводският реостат S32 (врътката до копчето за светлините) нормално регулира яркостта на таблото.  
С тази схема тя **допълнително** управлява силата на звука на радиото чрез симулиране на бутоните на волана (SWRC).

---

## Принцип на работа

```
S32 (врътка) ──► [делител] ──► ATtiny85 ADC
                                    │
                              Засича посоката
                              на завъртане
                                    │
                          ┌─────────┴─────────┐
                          ▼                   ▼
                    VOL+ пулс            VOL- пулс
                          │                   │
                    [R=470Ω]              [R=1kΩ]
                          │                   │
                          └────────┬──────────┘
                                   │
                            SWRC вход на радио
```

**ATtiny85 чете напрежението на S32 10 пъти в секунда.**  
При промяна в посока "увеличение" → изпраща кратък пулс за VOL+.  
При промяна в посока "намаляване" → изпраща кратък пулс за VOL-.  
S32 **продължава** да управлява ILL+ нормално — не е прекъсната тази функция!

---

## SWRC (Steering Wheel Remote Control) — Как работи

Опел радиото има вход **SWRC** (или **SWC**) — това е същият вход за бутоните на волана.  
Вътре в радиото има pull-up резистор (~10kΩ към +5V).  
Различни бутони симулират различни съпротивления към маса:

| Бутон | Съпротивление към GND | Напрежение (при 10kΩ pull-up) |
|-------|-----------------------|-------------------------------|
| Нищо (свободен) | ∞ | ~5V |
| Volume + | ~470Ω | ~0.22V |
| Volume - | ~1000Ω | ~0.45V |
| Mute / Source | ~2200Ω | ~0.89V |

> **Важно:** Тези стойности са за CD30/CD40/Navi 600 на Opel.  
> **Трябва да ги измериш за твоето конкретно радио!** Виж раздел "Калибрация на SWRC" по-долу.

## Хардуерна схема

### Компоненти

| Компонент | Стойност | Брой |
|-----------|---------|------|
| ATtiny85 | DIP-8 | 1 |
| Регулатор 5V | 78L05 | 1 |
| NPN Транзистор | BC547 или 2N3904 | 2 |
| Резистор (SWRC VOL+) | 470Ω | 1 |
| Резистор (SWRC VOL-) | 1kΩ | 1 |
| Резистор (бази транзистори) | 10kΩ | 2 |
| Резистор (S32 делител горен) | 10kΩ | 1 |
| Резистор (S32 делител долен) | 10kΩ | 1 |
| Кондензатор | 100nF | 2 |
| Кондензатор | 10µF/25V | 1 |

### Схема

```
        KL15 (+12V)
             │
         [78L05]
             │
          +5V ──────────────────────────────────── ATtiny85 VCC (Pin 8)
             │                                               │
             │                                           ATtiny85
             │                                               │
S32 wiper ──┤                     PB2 (Pin 7) ◄──── ADC вход
             │                                               │
       [R_top: 10kΩ]                               PB0 (Pin 5) ──[10kΩ]──► BC547_1 база
             │                                               │               │
       S32 wiper (средна точка) ────────────────► ATtiny85 ADC              BC547_1 Collector ──[470Ω]──┐
             │                                               │                                            │
       [R_bot: 10kΩ]                               PB1 (Pin 6) ──[10kΩ]──► BC547_2 база               │
             │                                               │               │                            │
            GND                                    GND (Pin 4)              BC547_2 Collector ──[1kΩ]───┤
                                                                             │                            │
                                                                            GND                    SWRC вход на радио
                                                                             │
                                                             BC547 Emitters ─── GND
```

### Опростена схема (текст)

```
KL15 ──[78L05]──+5V──────────────────────── ATtiny85 Pin 8 (VCC)
                                             ATtiny85 Pin 4 (GND) ── маса

S32 среден извод ──[10kΩ горен]──+5V
S32 среден извод ──[10kΩ долен]──GND
S32 среден извод ─────────────────────────── ATtiny85 Pin 7 (PB2/ADC1)

ATtiny85 Pin 5 (PB0) ──[10kΩ]──► BC547(Q1) база
                                   Q1 емитер ──── GND
                                   Q1 колектор ──[470Ω]──► SWRC

ATtiny85 Pin 6 (PB1) ──[10kΩ]──► BC547(Q2) база
                                   Q2 емитер ──── GND
                                   Q2 колектор ──[1kΩ]───► SWRC

SWRC ────────────────────────────────────────────────────► Радио SWRC вход
```

## Калибрация на SWRC стойностите за твоето радио

Преди запояване — измери с мултиметър каква съпротивление имат бутоните на волана:

### Ако имаш бутони на волана:
1. Извади SWRC конектора от радиото
2. Мери съпротивлението между SWRC пин и GND при натиснат VOL+ бутон
3. Мери при VOL- бутон
4. Запиши стойностите и смени резисторите в схемата

### Ако нямаш бутони на волана:
1. Намери SWRC пина в радио конектора (вижте по-долу)
2. Мери напрежение на SWRC пина при включено радио (трябва да е ~5V при свободен вход)
3. Пробвай с временен резистор (470Ω към GND) — дали се усилва/намалява звука

### SWRC пин в радио конектора (Opel стандарт)

| Радио модел | SWRC пин |
|-------------|---------|
| CD30 MP3 | ISO конектор, пин A7 (жълто/кафяв) |
| CD40 USB | ISO конектор, пин A7 |
| Navi 600/650 | ISO конектор, пин A7 |
| CDC 40 | ISO конектор, пин A7 |

> Stандартният ISO A конектор (черен, 8 пина) на Opel:  
> A1=Mute, A2=VSS/GND_audio, A3=+12V acc, A4=Mute/Tel,  
> A5=ANT, A6=ANT_ctrl, **A7=SWRC**, A8=+12V perm
