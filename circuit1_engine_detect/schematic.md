# Circuit 1 — Engine Start Detector
## Opel Vectra C DRL — активиране само при работещ двигател

### Принцип на работа

LM393 сравнява **D+ напрежението на алтернатора** (мащабирано) с **фиксирано референтно напрежение**:
- Двигателят НЕ работи → D+ ≈ 0V → компараторът изключва MOSFET → DRL не светва
- Двигателят РАБОТИ → D+ ≈ 14.2V → компараторът включва MOSFET → DRL активен

### Схема

```
                    KL30 (+12V)
                        │
                     [R1: 47kΩ]
                        │
                  ┌─────┤
                  │     │
               [R2: 33kΩ]        ← Референтен делител: Vref = 4.95V
                  │
                 GND

              Vref ──────────────► LM393 Pin 2 (−) Инвертиращ


   D+ (Алтернатор)
        │
     [R3: 10kΩ]
        │
  ┌─────┤
  │     │
[R4: 10kΩ]          ← Входен делител: V_in = D+/2
  │
 GND

         V_in ─────────────────► LM393 Pin 3 (+) Неинвертиращ

                                         KL15 (+12V при запалване)
                                              │
                               [R5: 10kΩ]────┤ ← Pull-up
                                              │
LM393 Pin 1 (Output, open-collector) ────────┤
                                              │
                         [R_hyst: 1MΩ] ───────┤──► LM393 Pin 3 (+)
                                              │    (хистерезис ~0.1V)
                                              │
                                         IRFZ44N Gate
                                              │
                                         IRFZ44N Source ──── GND (маса)
                                              │
                                         IRFZ44N Drain ─────► DRL Реле намотка (−)
                                                              DRL Реле намотка (+) ─── KL30
                                                              │
                                                         [D1: 1N4007] ← Freewheeling diode
                                                         (паралелно на намотката, обратна полярност)


   DRL Реле Контакти:
   COM ─── KL30
   NO  ─── Балласт Trigger / Ксеноново реле управление
```

### Изчисление на компонентите

```
Референтно напрежение:
  Vref = VCC × R2/(R1+R2) = 12 × 33000/(47000+33000) = 4.95V

Входно напрежение при D+ = 14.2V (двигателят работи):
  V_in = 14.2 × R4/(R3+R4) = 14.2 × 10000/(10000+10000) = 7.1V

Входно напрежение при D+ = 0V (двигателят спрян):
  V_in = 0V

Праг на превключване (при V_in = Vref):
  D+_threshold = Vref × (R3+R4)/R4 = 4.95 × 2 = 9.9V

Хистерезис (с R_hyst = 1MΩ, R5 = 10kΩ):
  ΔV ≈ VCC × R_in_parallel / R_hyst ≈ незначителен, но стабилизира превключването
```

### Логическа таблица

| Условие | D+ | V_in на Pin 3 | V на Pin 2 | Pin 3 > Pin 2? | Изход | MOSFET | DRL |
|---------|----|----|----|----|----|----|-----|
| Двигател изкл. | 0V | 0V | 4.95V | НЕ | LOW | OFF | ❌ Изкл. |
| Само контакт (KL15) | ~0V | ~0V | 4.95V | НЕ | LOW | OFF | ❌ Изкл. |
| Двигател пален | 14.2V | 7.1V | 4.95V | ДА | HIGH (pull-up) | ON | ✅ Вкл. |

### LM393 — важни особености

- **Open-collector изход:** Нуждае се от pull-up резистор (R5)
- **Захранване:** Максимум 36V, работи от 5V до 36V — идеален за 12V автомобилни системи
- **Консумация:** <1mA — negligible
- **Скорост:** Достатъчна за тази приложение (не е критична)

### IRFZ44N — параметри

| Параметър | Стойност |
|-----------|---------|
| V_DS (макс) | 55V |
| I_D (макс) | 49A |
| R_DS(on) | 17.5 mΩ |
| V_GS(th) | 2–4V |
| Пакет | TO-220 |

IRFZ44N е прекомерно оразмерен за DRL реле намотка (~200mA), но е лесно достъпен и много надежден.

### Защитни мерки

1. **Freewheeling диод (D1):** Паралелно на реле намотката — защита срещу индуктивни пикове при изключване
2. **100nF кондензатор:** Паралелно на захранването на LM393 — декуплиращ
3. **Монтаж:** Далеч от топлинни източници; MOSFET на малък радиатор ако е нужно
