# Circuit 3 — Needle Sweep при стартиране
## Opel Vectra C 2008 — EEPROM модификация (без запояване)

Променяме 7 байта в паметта на таблото → при всяко запалване иглите
автоматично се завъртат до максимум и се връщат.

---

## Какво купуваш

| Хардуер | Цена | Където |
|---------|------|--------|
| CH341A USB програматор + SOIC8 клип | ~10–12 лв | AliExpress |

Търси: **`CH341A programmer SOIC8 clip 93CXX`**

> SOIC8 клипът се закача върху чипа без запояване — просто го защипваш.

---

## Как става — 5 стъпки

```
1. Изваждаш таблото от колата
2. Закачаш SOIC8 клипа върху 93C66 чипа
3. Четеш файла → правиш backup
4. Променяш 7 байта
5. Записваш обратно → слагаш таблото
```

**Без запояване. Без ESP32. Без сложни инструменти.**

---

## Стъпка 1 — Изваждане на таблото

1. Дръпни рамката около таблото с ръце (само клипси — без инструменти)
2. Отвий 2 болта (Torx T20) горе
3. Изкарай таблото напред внимателно
4. Отщекни 2 конектора отзад
5. Сложи таблото на маса

---

## Стъпка 2 — Намиране на 93C66 чипа

93C66 е малко SOIC8 чипче (8 пина, 2 реда по 4) на PCB-то на таблото.

**Как да го разпознаеш:**
- Надписан е `93C66` или `93LC66` или `M93C66`
- SOIC8 корпус (около 5×4mm)
- Обикновено е в горния ъгъл на PCB-то

```
Таблото отзад (PCB):
┌─────────────────────────────┐
│                             │
│  [93C66]  ◄── ТОВА търсиш  │
│                             │
│    [Главен процесор]        │
│                             │
└─────────────────────────────┘
```

> Ако не намериш — провери с лупа или телефон. Надписът е много малък.

---

## Стъпка 3 — Четене с CH341A

### Нужен софтуер (безплатен)
- **AsProgrammer** — [github.com/nofeletru/UsbAsp-flash](https://github.com/nofeletru/UsbAsp-flash/releases)
- Или **CH341A Programmer** (търси в Google)

### Свързване

```
CH341A                    93C66 чип (SOIC8)
                          ┌─────────────┐
VCC ──────────────────────┤ 8  VCC      │
CLK ──────────────────────┤ 6  CLK      │
MISO (SO) ────────────────┤ 5  DO       │
MOSI (SI) ────────────────┤ 4  DI       │  ← ориентация: точката е Pin 1
CS ───────────────────────┤ 1  CS       │
GND ──────────────────────┤ 4  GND      │
                          └─────────────┘
```

> SOIC8 клипът се закача директно — всички контакти се свързват автоматично.
> Само внимавай за ориентацията: **точката/вдлъбнатинката на чипа = Pin 1**.

### В AsProgrammer:
1. Свържи CH341A с USB
2. **IC** → избери `93C66` (или `93xx → 93C66`)
3. **Read** → изчакай
4. **File → Save** → запази като `vectra_cluster_BACKUP.bin`

**Backup-ът е задължителен!** Пази го на сигурно място.

---

## Стъпка 4 — Промяна на байтовете

Отвори `vectra_cluster_BACKUP.bin` в hex редактор:
- **HxD** (Windows, безплатен) — hxd.de
- Или всеки друг hex редактор

### Байтовете за промяна:

| Адрес | Преди | След |
|-------|-------|------|
| `0x0B` | `0E` | `1E` |
| `0x0CA` | `00` | `A0` |
| `0x0CB` | `00` | `64` |
| `0x0CC` | `00` | `FA` |
| `0x0CD` | `00` | `FA` |
| `0x0CE` | `00` | `FA` |
| `0x0CF` | `00` | `FA` |

**Общо: 7 байта.**

### В HxD:
1. **Ctrl+G** → въведи адрес `0B` → намери байта → смени `0E` на `1E`
2. **Ctrl+G** → въведи адрес `CA` → намери 6 нулеви байта → смени на `A0 64 FA FA FA FA`
3. **File → Save As** → запази като `vectra_cluster_MODIFIED.bin`

> **Никога не презаписвай оригиналния backup файл!**

---

## Стъпка 5 — Записване обратно

В AsProgrammer:
1. **File → Open** → избери `vectra_cluster_MODIFIED.bin`
2. **Program** (или Write) → изчакай
3. **Verify** → трябва да е OK
4. Свали SOIC8 клипа
5. Върни таблото в колата

---

## Резултат

При всяко запалване:
```
Ключ в позиция II
      │
      ▼
Всички стрелки → максимум (~1.5 сек)
      │
      ▼
Всички стрелки → нула
      │
      ▼
Нормална работа
```

---

## Ако нещо се обърка

Имаш backup → просто запиши оригиналния файл обратно.
Таблото се връща в точно същото състояние.

**Цена:** ~12 лв. **Трудност:** Ниска. **Риск:** Нисък ако пазиш backup.

---

## Алтернатива — ATtiny85 (стара версия)

Ако не искаш да пипаш EEPROM-а, в папката има `attiny85_sweep.ino` —
външен чип, запоен към стъпковия мотор. По-сложно, резултатът е същият.
