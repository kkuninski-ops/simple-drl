# Simple DRL — Opel Vectra C 2008 (Xenon D1S/H1)

Хардуерна схема с **op-amp компаратор (LM393)** и **N-channel MOSFET (IRFZ44N)** за решаване на два проблема при активиран OpCom DRL Version 3.

---

## Проблеми и решения

### Проблем 1 — Фаровете светват при контакт (KL15), а не при пален двигател

**Причина:** OpCom DRL v3 активира фаровете при появата на KL15 (запалване, позиция II), независимо дали двигателят работи.

**Решение:** LM393 компаратор следи напрежението на **D+ терминала на алтернатора**. Когато двигателят работи, алтернаторът зарежда с ~14.2V → компараторът отваря MOSFET-а → DRL реле се активира. При само контакт (~12V) → MOSFET заключен → фаровете не светват.

---

### Проблем 2 — В AUTO режим не може да се регулира яркостта на радиото

**Причина:** В AUTO режим BCM-ът (A15, конектор XC31) подава фиксиран PWM сигнал на ILL+ линията, заобикаляйки реостата S32.

**Решение:** LM358 op-amp (voltage follower) + P-channel MOSFET (IRF9540) се включват в серия с ILL+ линията към радиото, позволявайки ръчно регулиране чрез допълнителен потенциометър.

## Схема — Circuit 1: Engine Start Detection (Problem 1)

```
KL30 (+12V постоянно)
    │
    ├─[R1: 47kΩ]─┬─[R2: 33kΩ]─GND
    │             │
    │          Vref = 4.95V ──► LM393 Pin 2 (−) Inverting
    │
D+ (Алтернатор)
    │
    ├─[R3: 10kΩ]─┬─[R4: 10kΩ]─GND
                  │
               V_D+ scaled ──► LM393 Pin 3 (+) Non-inverting

LM393 Pin 8 (VCC) ──── KL15 (+12V при запалване)
LM393 Pin 4 (GND) ──── Маса

LM393 Pin 1 (Output, open-collector)
    │
    ├─[R5: 10kΩ pull-up]─── KL15 (+12V)
    │
    ├─[R_hyst: 1MΩ]──────── LM393 Pin 3 (+)  ← хистерезис
    │
    └──► IRFZ44N Gate
         │
    IRFZ44N Source ─── GND (маса)
    IRFZ44N Drain  ─── DRL Реле (отрицателна намотка)
         │
    DRL Реле (положителна намотка) ─── KL30
    DRL Реле (контакти) ─── Управление на балластите D1S
```

### Напрежения и прагове

| Условие | D+ напрежение | V на pin 3 | V на pin 2 | Изход | MOSFET |
|---------|--------------|-----------|-----------|-------|--------|
| Двигател изкл. | ~0V | 0V | 4.95V | LOW | OFF (фарове изкл.) |
| Само контакт | ~12V (батерия, без зареждане) | 6.0V | 4.95V | HIGH | ON ⚠️ |
| Двигател пален | ~14.2V (зареждане) | 7.1V | 4.95V | HIGH | ON ✓ |

> **Важно:** При само контакт без стартиране D+ остава ~0V (алтернаторът е спрян). Веднага щом двигателят се пали, D+ скача до ~14V. Праговото напрежение е настроено на ~10V D+ (≈5.0V scaled), добре между 0V и 14V.

## Схема — Circuit 2: ILL+ Dimmer (Problem 2)

```
BCM ILL+ изход (XC31, pin 23*)
    │
    [R_series: 100Ω]
    │
    └──► IRF9540N Source (P-ch MOSFET)
         │
    IRF9540N Drain ──► Радио ILL+ вход
         │
    IRF9540N Gate ──► LM358 Op-amp изход (voltage follower)

LM358 конфигурация (voltage follower):
    Pin 3 (+) ─── Потенциометър (10kΩ) изход (0 до 10V)
    Pin 2 (−) ─── Pin 1 (изход) ← обратна връзка
    Pin 8 (VCC) ── KL15 (+12V)
    Pin 4 (GND) ── Маса

Потенциометър:
    Единият край ─── KL15 (+12V)
    Другият край ─── GND
    Средата ────── LM358 Pin 3 (+)
```

> *Точният пин на XC31 за ILL+ трябва да се верифицира с мултиметър при включена подсветка.

## Точки за свързване в автомобила

### D+ сигнал (за Problem 1)
- **Алтернатор:** D+ терминал на алтернатора (малкият щекер/щифт)
- **Или:** Проводникът на индикатора за зареждане зад табло (от алтернатора към комбинирания уред)
- **Цвят:** Обикновено **зелен** или **зелено/бял** (верифицирай с мултиметър!)

### DRL реле управление (за Problem 1)
- Намери DRL реле (монтирано от теб при ретрофита или вградено в ксеноновия балласт)
- Включи MOSFET в серия с управляващата намотка на релето

### ILL+ линия за радиото (за Problem 2)
- **Радио конектор:** пин ILL+ (обикновено оранжев или оранжево/бял)
- Прекъсни линията и включи P-ch MOSFET схемата в серия
- Потенциометърът се монтира на достъпно място в конзолата

## Инсталация

1. **Изключи батерията** преди монтаж
2. Намери D+ проводника с мултиметър (14V при работещ двигател, 0V при изключен)
3. Намери DRL реле управляващия проводник (12V при активен DRL, 0V при изкл.)
4. Намери ILL+ проводника на радиото (мерено спрямо маса при включена подсветка)
5. Монтирай платката на защитено от влага и топлина място
6. Тествай с мултиметър преди сглобяване
