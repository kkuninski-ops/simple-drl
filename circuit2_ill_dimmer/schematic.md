# Circuit 2 — ILL+ Radio Dimmer
## Ръчно регулиране на яркостта на радиото в AUTO режим

### Проблем

В AUTO режим BCM (A15, конектор XC31) подава фиксиран PWM сигнал на ILL+ линията.
Реостатът S32 (на таблото) се игнорира от BCM в AUTO режим.
Резултат: яркостта на радиото е фиксирана и не може да се регулира.

### Решение

Вмъкваме **P-channel MOSFET (IRF9540N)** в серия с ILL+ линията към радиото.
**LM358 op-amp** (voltage follower) управлява гейта на MOSFET-а от ръчен потенциометър.

### Принцип на работа

```
BCM ILL+ ──► MOSFET (P-ch) ──► Радио ILL+
                  ↑
              LM358 Voltage Follower
                  ↑
              Потенциометър (ръчно)
```

- При потенциометър на максимум: MOSFET напълно проводи → радиото получава пълно BCM ILL+ ниво
- При потенциометър на минимум: MOSFET частично блокира → радиото получава намалена яркост

### Схема

```
BCM ILL+ изход
        │
   [R1: 100Ω]          ← Ограничителен резистор (защита)
        │
        └──────────────► IRF9540N Source (S)
                              │
                         IRF9540N Drain (D) ──────────────► Радио ILL+ вход
                              │
                         IRF9540N Gate (G) ◄────── LM358 Pin 1 (изход)
                              │
                    ┌─────────┘
                    │
              LM358 Pin 1 (OUT)
              LM358 Pin 2 (−) ────┐ ← Обратна връзка (unity gain / voltage follower)
              LM358 Pin 3 (+) ────┼──── Потенциометър (средна точка)
                                  │
                    ┌─────────────┘
                    │
               KL15 (+12V)
                    │
               [Pot: 10kΩ] ← единият край
                    │
                   средата ──► LM358 Pin 3 (+)
                    │
                   GND ──► другият край
                    │
              LM358 Pin 8 (VCC) ──── KL15 (+12V)
              LM358 Pin 4 (GND) ──── Маса
```

### IRF9540N — параметри

| Параметър | Стойност |
|-----------|---------|
| Тип | P-channel MOSFET |
| V_DS (макс) | -100V |
| I_D (макс) | -23A |
| V_GS(th) | -2 до -4V |
| Пакет | TO-220 |

### Защо P-channel?

ILL+ линията е положителна (+12V при включена подсветка). P-channel MOSFET работи между Source (+ страна) и Drain (изход), управляван от Gate спрямо Source. Когато Gate = Source (висок потенциал) → MOSFET изключен. Когато Gate < Source → MOSFET включен.

LM358 voltage follower превежда 0–12V от потенциометъра директно в Gate напрежение.

### Алтернатива с N-channel (ако IRF9540N не е наличен)

```
BCM ILL+ ──► Радио ILL+ вход
                  │
             [R_shunt: 470Ω]
                  │
             IRFZ44N Drain
             IRFZ44N Source ──── GND
             IRFZ44N Gate ◄──── LM358 Output
```

В тази конфигурация N-channel MOSFET "изтегля" ток от ILL+ линията към маса, намалявайки ефективното напрежение на радиото. По-лесно за изпълнение, но с по-малко точен контрол.

### Монтаж

1. Намери ILL+ пина на радио конектора (оранжев/сив, ~12V при включена подсветка)
2. Прекъсни ILL+ проводника (не маса!)
3. BCM страна → R1 → IRF9540N Source
4. IRF9540N Drain → Радио ILL+ вход
5. Монтирай потенциометъра на достъпно място (под радиото или в конзолата)
6. Свържи LM358 захранването към KL15 (само при запалване)

### Тест

1. Включи запалването
2. Включи AUTO режим на ключа за светлините
3. Завъртай потенциометъра — яркостта на радиото трябва да се променя
4. При спиране (изключено запалване) — LM358 без захранване → MOSFET изключен → ILL+ = 0V (нормално)
